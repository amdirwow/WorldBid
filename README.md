# WorldBid

Аукціонний помічник для WoW 3.3.5a.

## Показ вікна

- Типово WorldBid відкривається разом із сумками (`Shift+B`).
- Через шестерню біля кнопки закриття можна вибрати режим «Тільки вручну командою `/wbid`».
- Там само можна заблокувати позицію вікна або вимкнути його автоматичне закриття разом із сумками.
- Показ серверних оголошень аукціону перемикається через `.bid ignore` окремо для кожного персонажа.

Додаткові команди: `/wbid settings`, `/wbid bags`, `/wbid command`, `/wbid show`, `/wbid hide`, `/wbid reset`.
